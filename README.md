# Omarchy Config

This repository exists to help me quickly reconfigure a fresh Omarchy Linux installation exactly the way I like it.

Omarchy is my favourite operating system and this repo acts as my personal reference for:

- System configuration
- Development environment setup
- Networking utilities
- Wake-on-LAN scripts
- Headless server configuration
- GPU and AI tooling
- Tailscale setup
- Bootloader tweaks
- Monitoring and automation
